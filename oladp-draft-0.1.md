# Open Labels AI Document Project (OLADP) [AC-TI]

**Status:** Draft 0.1

**Purpose:** A simple, open standard for labeling AI usage within individual elements of a document.

## 1. Overview

The Open Labels AI Document Project (OLADP) provides a simple way to indicate:

1. **AI usage when developing content.**
2. **In reference to elements of the document.**

[AC-LS]

A label is placed at the end of the element it describes using this syntax:

```text
[AIUSAGE-ELEMENT]
```

For example:

```text
[AC-PA]
```

means that the paragraph was created collaboratively by a human and AI.

The standard describes the **role of AI in producing content**, not a percentage of content attributable to AI. It makes no judgment about the quality, accuracy, value, or appropriateness of AI use.

## 2. AI Usage Codes

| Code | Category | Definition |
|---|---|---|
| **HU** | Human | Human authored. AI use is limited to basic spelling, grammar, etc. Default if no label provided. |
| **AS** | AI Assisted | Human authored the substance of the content. AI was used to help complete, polish, clarify, or lightly rewrite human-created content. |
| **AC** | AI Collaborative | Human and AI substantially co-created the content through an iterative process. Both materially contributed to the resulting content. |
| **AG** | AI Generated | AI generated the content, after which a human reviewed, edited, and/or approved it before release. |
| **AA** | AI Autonomous | AI generated and released the content without human review before release. |

[AC-TC]

These codes are categories, not a numerical scale. For example, `AC` should not be interpreted as a specific percentage of AI-generated content.

## 3. Element Codes

| Code | Element | Definition |
|---|---|---|
| **TI** | Title | A title or heading. |
| **SE** | Sentence | A single sentence. |
| **PA** | Paragraph | A paragraph or equivalent block of prose. |
| **LS** | List | A bulleted, numbered, or otherwise structured list. |
| **SC** | Section | A named or logically distinct section of a document. |
| **PG** | Page | A rendered page of a document. |
| **DC** | Document | The complete document. |
| **IM** | Image | An image, illustration, photograph, or other visual asset. |
| **TC** | Table/Chart | A table, chart, graph, or similar structured visualization. |
| **CD** | Code | Source code, configuration, scripts, or other machine-readable code included in the document. |

[AC-TC]

`PG` is provided for formats where page-level labeling is useful, although semantic elements such as paragraphs and sections are generally preferable because pagination can change when a document is reformatted.

## 4. Label Syntax

The standard label is:

```text
[<AI usage code>-<element code>]
```

Examples:

```text
[HU-PA]  Human-authored paragraph
[AS-SE]  AI-assisted sentence
[AC-PA]  Human/AI collaborative paragraph
[AG-SC]  AI-generated, human-reviewed section
[AA-DC]  Autonomous AI-generated document
[AG-IM]  AI-generated image reviewed by a human
[AC-TI]  Human/AI collaborative title
[AG-LS]  AI-generated, human-reviewed list
```

The label SHOULD appear at the **end of the element it describes**.

Example:

```text
Artificial intelligence is changing how people create and edit written material. Humans can use AI as anything from a proofreading tool to a collaborative writing partner. [AC-PA]
```

## 5. Inheritance

A label applied to a larger element applies to its contained elements unless a more specific label overrides it.

For example, a section marked:

```text
[AC-SC]
```

indicates that the section is AI Collaborative unless a paragraph, sentence, image, table, list, title, or other contained element has its own label.

A document could therefore contain:

```text
Document default: [AS-DC]

Section 1
...content...
[AC-SC]

A particular paragraph generated by AI and reviewed by the author. [AG-PA]
```

The most specific applicable label takes precedence.

## 6. Human Responsibility

The standard records **AI usage and human involvement**, not correctness.

In particular, `AG` means that a human reviewed, edited, and/or approved AI-generated material before release. It does not by itself certify that every factual claim was independently verified.

Likewise, `HU` indicates the method of authorship; it does not imply that the content is more accurate than content carrying another classification.

## 7. Design Principles

The standard is intended to be:

- **Human readable** — the notation can be understood without specialized software.
- **Machine readable** — labels have a predictable syntax that software can identify and process.
- **Element specific** — different portions of the same document can accurately describe different uses of AI.
- **Nonjudgmental** — classifications describe how content was produced rather than rating AI use as good or bad.
- **Simple** — authors can use the standard manually without requiring provenance infrastructure.
