# Open Labels AI Document Project (OLADP)

**A simple, open standard for labeling AI usage in documents.**

AI is increasingly used to write, edit, and generate content. Yet readers often have no clear way to understand how AI contributed to what they're reading. Existing disclosure approaches can be complicated, inconsistent, or apply only to an entire document.

OLADP takes a simpler approach. It provides a lightweight, human-readable way to identify AI usage in individual elements of a document, such as sentences, paragraphs, sections, and images.

This approach offers several benefits:

- **Transparency** — Readers can understand how AI contributed to the content they consume.
- **Granularity** — AI usage can be identified for individual elements rather than an entire document.
- **Simplicity** — Short, consistent labels require no special software or technical knowledge.
- **Accountability** — Distinguishing between human-reviewed and unreviewed AI content helps readers make informed judgments.
- **Flexibility** — The approach works with different document formats and publishing platforms.

The goal is not to judge whether AI usage is good or bad. It is to give readers useful information so they can make their own decisions.
